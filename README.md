A MLOps-based repo. It includes testing phase using containerized jupyter notebooks. Pending orchestration and deployment. Deployment will use DRF and CI/CD pipelines via github actions. 

## Stack
- Django 6 + Django REST Framework
- PostgreSQL (Supabase)
- Docker + Docker Compose
